# Мої витрати

Навчальний вебзастосунок українською мовою для домашнього завдання «JavaScript в інтерфейсі: DOM, події, форми та зберігання даних».

## Можливості

- Додавання та видалення витрат із перевіркою назви, суми й категорії.
- Загальна сума та суми за категоріями в гривнях; обчислення ведуться в копійках.
- Пошук за назвою, фільтр за категорією й очищення всіх витрат із підтвердженням.
- Збереження витрат у `localStorage` браузера й відновлення після перезавантаження.
- Демонстраційна форма реєстрації з перевіркою JavaScript без перезавантаження сторінки. Дані реєстрації та паролі не зберігаються й не надсилаються.

## Запуск

Відкрийте `index.html` у браузері. Сервер, збірка та встановлення пакетів не потрібні.

## Файли

- `index.html` — розмітка сторінки.
- `style.css` — адаптивне оформлення.
- `script.js` — перевірка форм, обробка подій, підрахунки та зберігання.
- `script.test.js` — перевірки основної логіки. Запуск: `node script.test.js`.

Витрати зберігаються лише в поточному браузері під ключем `expense-tracker-v1`. Якщо очистити дані сайту в браузері, записи зникнуть.
